
# CoinFlow 🌍💱

**CoinFlow** is a real-time currency dashboard built with Python and Tkinter. Track multiple currencies with live updates, color-coded trends, and smooth mini-graphs. The responsive layout adjusts automatically, providing a clear, dynamic view of global exchange rates.

## Features

- Monitor multiple currencies simultaneously (USD, EUR, GBP, JPY, CNY, CAD, AUD, and more).  
- Real-time updates every few seconds with color-coded trends:  
  - 🔴 Red: Currency increased  
  - 🟢 Green: Currency decreased  
  - ⚪ White: No change  
- Smooth, detailed mini-graphs for each currency.  
- Responsive dashboard layout that automatically rearranges charts.  
- Lightweight and visually clear, ideal for investors and traders.

## Technologies Used

- Python 3  
- Tkinter (GUI)  
- Matplotlib (charts)  
- NumPy, SciPy (data processing)  
- Requests (API calls)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/CoinFlow.git
cd CoinFlow
````

2. Install dependencies:

```bash
pip install requests matplotlib numpy scipy
```

## Usage
Run the dashboard:

```bash
python coinflow.py
```

* The dashboard opens with multiple currency cards and auto-updating mini-graphs.
* Resize the window to automatically rearrange the charts.
